## Requirements
### Requirement: Latest Arrivals Header Button Alignment
The system SHALL vertically center align the "View All Inventory" header button with the section title and subtitle block in the Latest Arrivals section (`resources/views/sections/cars-latest.blade.php`).

#### Scenario: User views Latest Arrivals section header
- **WHEN** the user views the Latest Arrivals section header
- **THEN** the "View All Inventory" button SHALL sit vertically center-aligned alongside the section heading and subtitle block.
